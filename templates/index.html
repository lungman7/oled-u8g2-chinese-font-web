接上 Arduino

三步驟開始顯示

  1. 安裝函式庫Arduino IDE → 函式庫管理員，搜尋並安裝 U8g2。
  2. 放入字型檔把下載的 u8g2_font_zh_custom_24.h 放到 .ino 同一個資料夾。
  3. Include 並顯示程式檔請使用 UTF-8 編碼，中文必須包含在剛才輸入的文字內。
OLED_Chinese.ino
#include <Arduino.h>
#include <U8g2lib.h>
#include "u8g2_font_zh_custom_24.h"

// 請依 OLED 型號修改建構式
U8G2_SSD1306_128X64_NONAME_F_HW_I2C u8g2(
  U8G2_R0, U8X8_PIN_NONE
);

void setup() {
  u8g2.begin();
  u8g2.enableUTF8Print();
}

void loop() {
  u8g2.clearBuffer();
  u8g2.setFont(u8g2_font_zh_custom_24);
  u8g2.setFontPosTop();
  u8g2.drawUTF8(0, 0, "溫度正常");
  u8g2.sendBuffer();
  delay(1000);
}
記憶體提醒

48 × 48 字模會明顯增加 Flash 用量。建議只輸入實際會顯示的字，並避免一次收錄整套中文字。

1偵測本機字型

只檢查常見中文字型名稱，不讀取個人文件。

2瀏覽器繪製點陣

字形在你的電腦完成單色化，完整字型檔不會上傳。

3樹莓派轉成 U8g2

使用官方 bdfconv 格式，下載後可直接 include。
